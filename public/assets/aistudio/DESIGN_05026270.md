## Brand & Style

This design system establishes an engineering-first, developer-centric digital marketplace tailored for Arabic (RTL) automation practitioners, technical founders, and operations leaders. The aesthetic balances deep technical credibility with immediate commerce clarity: sharp monoline structural framing, node-and-graph layout logic, and expansive whitespace.

### Personality & Tone
- **Precision Engineering:** Clean geometric structure reminiscent of workflow visual canvas nodes and execution telemetry.
- **Immediate Trust & Clarity:** Frictionless single-item purchase velocity with zero noise—no auth gates, no carts, no bloated onboarding.
- **Technical Rigor:** Strict 8px baseline cadence, disciplined borders, crisp monoline micro-indicators, and legible Arabic typography with generous line heights.

### Visual Architecture
The layout uses an **Experimental Technical** style: crisp `#E2E8F0` structural boundaries, subtle `#EEF2F9` tinted control planes, and high-impact `#2563EB` interactive nodes against a pristine `#FFFFFF` and `#F8FAFC` foundation.

## Colors

The system uses a strictly light, high-contrast palette calibrated for code-level clarity and clean RTL reading ergonomics. Dark mode is intentionally omitted to maintain consistent engineering documentation clarity.

### Color Tokens & Assignments
- **Primary (`#2563EB`):** High-energy electric cobalt. Drives primary interactive states, immediate call-to-action buttons, active chip selections, and focused node states.
- **Secondary (`#1E3A8A`):** Deep brand navy. Anchors high-level structural items, category tabs, and strong technical headers.
- **Tertiary / Success (`#16A34A`):** Verification emerald. Reserved for workflow verification badges, checklist deliverables, execution status indicators, and guarantees.
- **Neutral Canvas (`#0F172A` / `#334155` / `#64748B`):** 
  - Text Primary: `#0F172A` (deep slate navy for terminal clarity in headings).
  - Text Body: `#334155` (softened reading slate at 1.7 line height).
  - Text Muted: `#64748B` (metadata, secondary specs, execution parameters).
- **Surfaces & Borders:**
  - Base Canvas: `#F8FAFC`.
  - Surface Cards & Nodes: `#FFFFFF`.
  - Accent / Hero Shading: `#EEF2F9` and `#EFF6FF`.
  - Structural Division: `#E2E8F0` (clean, 1px border lines across cards and table cells).

## Typography

The type scale integrates technical numeric typography with balanced RTL text rendering. Primary English glyphs and alphanumeric identifiers rely on Space Grotesk and Geist, paired seamlessly with Cairo and IBM Plex Sans Arabic font stacks for pure RTL legibility.

### Guidelines
- **Strict RTL Alignment:** Default text aligns right (`text-align: right; direction: rtl;`). Numeric metrics, workflow node parameters, and version IDs use monospaced numerals with `dir="ltr"` encapsulation where needed.
- **Airy Line Height:** Standard Arabic body text requires a strict `1.7` line-height multiplier to prevent diacritical and ascender/descender crowding.
- **Hierarchy Stacking:** Bold geometric headlines are paired with muted technical metadata tags to create clear scannability across dense workflow specifications.

## Layout & Spacing

Layout geometry follows an exact **8px spatial grid**. Content relies on a structured 12-column system on desktop, collapsing to 6 columns on tablet, and a single-column stack on mobile.

### Spatial Rhythm
- **Gutters & Padding:** 24px (`1.5rem`) on desktop; 16px (`1rem`) on mobile.
- **Vertical Spacing:** Generous whitespace separates workflow nodes and content blocks to preserve clarity: 40px (`2.5rem`) between major sections, 16px to 24px within node groups.
- **RTL Fluidity:** Layout margins flip logically (`margin-inline-start`, `margin-inline-end`). All directional offsets use logical CSS positioning to ensure natural RTL layout execution.

## Elevation & Depth

This design system uses a technical, flat-depth visual model. Depth is established through crisp, precise borders and slight tonal shifts rather than heavy blurs.

### Surface Tiers
- **Canvas Base:** `#F8FAFC` provides a neutral surface for all UI elements.
- **Surface Elevation 0 (Resting Cards):** `#FFFFFF` background with a crisp `1px solid #E2E8F0` border. No drop shadows.
- **Surface Elevation 1 (Interactive / Hover):** `#FFFFFF` with `1px solid #CBD5E1` and a soft, low-contrast shadow (`0 4px 12px -2px rgba(15, 23, 42, 0.05)`).
- **Surface Elevation 2 (Sticky Bars & Floating Controls):** `#FFFFFF` with `1px solid #E2E8F0` backed by `0 10px 25px -5px rgba(15, 23, 42, 0.08)`.
- **Node Focus / Active:** Border color transitions directly to `#2563EB` with an outer ring: `0 0 0 3px rgba(37, 99, 235, 0.12)`.

## Shapes

The shape system follows a soft, controlled radius scheme (`roundedness: 1`), conveying clean engineering discipline without overly round or playful visuals.

### Corner Radius System
- **Micro Radii (`rounded-sm` / 4px):** Applied to badges, tech stack tags, node port connectors, and language/currency selectors.
- **Component Radii (`rounded` / 8px to 10px):** Applied to primary CTA buttons, input triggers, and accordion bars. Primary CTA buttons are precisely fixed at `10px`.
- **Structural Radii (`rounded-lg` / 12px):** Applied to all product cards, n8n workflow node blocks, and interactive modals.
- **Floating Controls (`rounded-full`):** Reserved exclusively for circular utility icons, node connection pins, and the floating WhatsApp action button.

## Components

### Header & Navigation
- **Wordmark:** Monoline bold `ENGINITY` in Space Grotesk, prefixed with an interconnected node glyph (`●—●`).
- **Navigation Links:** Horizontal inline list (`المنتجات`, `كيف يعمل الشراء`, `الأسئلة الشائعة`) in slate `#334155` with `#2563EB` underline animations.
- **Segmented Controls (Currency & Language):** Dual inline toggles (`ج.م | $` and `AR | EN`) styled as clean pills with `#EEF2F9` track surfaces and `#FFFFFF` active chips with delicate borders.

### Workflow Node Cards & Graphs
- **Graph Visualizer:** Canvas node containers rendered with `12px` rounded corners, `#FFFFFF` surfaces, `#E2E8F0` borders, and connector dots (`8px` diameter, `#2563EB`).
- **Node Metadata:** Displays execution triggers, n8n version badges, and integration icons (Webhook, Airtable, OpenAI, WhatsApp API).

### Product Cards
- **Structure:** Clean white surface, 12px corner radius, 1px `#E2E8F0` border.
- **Header:** Node flow diagram preview or automation schematic with a light `#EEF2F9` background.
- **Tool Tags:** Inline flex chips with soft slate borders and tool labels (e.g., `n8n`, `Telegram`, `OpenAI`).
- **Footer:** Dynamic price block showing active currency with an instant-buy direct CTA button (`10px` radius, `#2563EB`).

### Buttons & Interactive Controls
- **Primary CTA:** Background `#2563EB`, text `#FFFFFF`, radius `10px`, font weight 600. Hover state darkens to `#1D4ED8`. Focus state displays an electric blue halo.
- **Direct Purchase Flow:** Buttons trigger immediate checkout/download links—no persistent shopping cart or account creation steps.

### Checklists & Deliverables
- **Success Items:** Unordered lists with `1.7` line height. Check icons feature a soft `#DCFCE7` circular background housing a `#16A34A` checkmark glyph.

### Accordion FAQs
- **Container:** Border-bottom `#E2E8F0` on white, or individual card style.
- **Header:** RTL flex layout with title on the right and an animated chevron on the left.
- **Expanded Body:** Line-height `1.7`, text `#334155`.

### Mobile Floating & Sticky Controls
- **Sticky Buy Bar:** Mobile-only fixed footer (`bottom: 0`, full width, white canvas, border-top `#E2E8F0`) presenting instant price and the primary `#2563EB` CTA.
- **Floating WhatsApp Support:** Pinned bottom-start at `bottom: 24px; left: 24px;`, featuring an emerald green `#22C55E` circle with crisp shadow elevation and an embedded chat glyph.
